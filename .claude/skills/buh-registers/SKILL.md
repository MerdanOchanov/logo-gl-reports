# Регистры и формы: справка

**Достоверность.** Макеты регистров ниже — **общая практика СНГ (советская/российская), НЕ туркменские бланки**: для Туркменистана бланков журналов-ордеров, шахматки, форм баланса и ОПУ с кодами строк в открытых источниках **не найдено**. Типовой план 2012 г. и НСФО их не предписывают. Метки: [НАЙДЕНО] — прочитано в источнике; [практика СНГ] — общие знания; [решение] — выбор проекта, согласовать с бухгалтером.

## 1. Что известно о Туркменистане [НАЙДЕНО]
- Типовой план счетов — приказ Минфина **№ 198-Ö от 05.11.2012** (рег. Минадалат № 670 от 17.11.2012; изм. № 35-Ö от 19.03.2014, № 115-Ö от 16.09.2015); основан на классификации СГФ/GFS 2001; **не советский/российский**: нет сквозных 01…99. Коды 6–8 знаков, 7 уровней (тип 1, категория 2, подкатегория 3, группа 4, подгруппа 5, синтетический 6, аналитический 8). Классы: 1 доходы, 2 расходы, 6 активы и обязательства (по ликвидности), 8 капитал, 9 забалансовые. Пример: 61114100 «Здания».
- Отчётность — НСФО (приказ № 12-Ö от 08.02.2012; для МСП № 57-Ö от 01.04.2013): отчёт о финансовом положении, о совокупной прибыли, об изменениях в капитале, о движении денежных средств, примечания; год 01.01–31.12; сравнительные данные обязательны. Задан **минимальный перечень статей** (п.58, п.65), **не бланк с кодами строк**.
- Все источники — неофициальный перевод редакций 2012–2015; актуальность после 2015 не проверена. Налоговые декларации (бланки, строки) **не найдены**.
- **Реальный учёт предприятия ведётся в турецком плане Tekdüzen (3-значные корни) в Logo**, не по Типовому плану 2012. Соответствие Tekdüzen ↔ Типовой план ↔ СНГ — [предположение] в `reference/plan-forms-tm.md`.
- **Запросить у бухгалтера** (полный список — там же): рабочий план и принцип сопоставления с «старыми» кодами; образцы реально сдаваемых баланса/ОПУ/налоговых/статистических форм со строками и графами; образцы регистров (ОСВ, шахматка, ЖО с нужными номерами, главная книга, мемориальные ордера) и кто их требует; какой стандарт (НСФО/МСФО).

## 2. Регистры [практика СНГ + факты Logo]
Базис: проводка = (Дт счёт, Кт счёт, сумма). Источник — Logo `EMFLINE` , листья по префиксу, `CANCELLED=0`, açılış отдельно.

**ОСВ (оборотно-сальдовая ведомость).** Строки — счета (дерево: уровни 0..4 через префикс); графы: сальдо на начало (Дт, Кт), обороты периода (Дт, Кт), сальдо на конец (Дт, Кт).
- Нач. = açılış + движения до начала периода; кон. = нач. + Дт − Кт (в нетто Дт−Кт).
- **Свёрнутое сальдо** [практика СНГ]: по счёту одно нетто (Дт−Кт); если >0 — в графе Дт, если <0 — в Кт. Так считает эталонный SQL проекта на каждом уровне плана (нетто группы, а не сумма сальдо подсчетов).
- **Развёрнутое сальдо** [практика СНГ]: Дт-сальдо и Кт-сальдо не зачитываются — по счёту суммируются отдельно дебетовые и кредитовые остатки его аналитик (контрагентов/субсчетов); у активно-пассивных счетов (расчёты 60/62/76, 120/320/329) обе графы могут быть заполнены. Нужно считать остатки на листьях и затем суммировать положительные и отрицательные отдельно. [решение] — какой вид нужен по умолчанию, спросить.
- Инварианты: (1) ΣДт оборотов = ΣКт оборотов (по всей ОСВ, для листьев/уровня 0); (2) для каждого счёта нач.нетто + Дт − Кт = кон.нетто; (3) родитель = Σ детей: нач.нетто, оборот Дт, оборот Кт и кон.нетто суммируются; графы сальдо Дт/Кт родителя получают из его нетто, а не суммой свёрнутых сальдо детей (при развёрнутом — суммой по листьям); (4) Σ нач.нетто = 0 и Σ кон.нетто = 0 по всем счетам (пока не закрыт результат); (5) при развёрнутом: Σ Дт-сальдо = Σ Кт-сальдо.
- Допуск сравнения 0.005, суммы округлять до 2 знаков.

**Шахматная ведомость (шахматка).** Матрица: строки — счета по дебету, столбцы — по кредиту, ячейка — оборот за период по корреспонденции Дт(строка)/Кт(столбец); итог строки = оборот Дт счёта, итог столбца = оборот Кт счёта; общий итог Дт = Кт. Инвариант проекта: итог шахматки = Σ оборотов ОСВ по каждому счёту и стороне; без açılış. Строится по корреспонденции (алгоритм AB/CROSSCODE/D); ячейки метода D (пропорционально) помечать «расчётная». Счёт-группу строить свёрткой листьев по префиксу.

**Главная книга (по [практике СНГ]).** Страница на счёт: шапка (счёт, название, сальдо на начало); строки по месяцам: обороты по Дт в корреспонденции с Кт счетов (колонки), итого Дт, обороты по Кт в корреспонденции с Дт счетов, итого Кт, сальдо на конец месяца; итог за год. Нужна корреспонденция (пары). Инвариант: итоги по месяцам = оборотам ОСВ; сальдо кон. месяца = нач. следующего. Примечание: турецкий defter-i kebir — это книга по счетам 1-го порядка (kebir = 3-значный корень), сходна по смыслу.

**Карточка счёта.** Хронология проводок счёта за период: дата, документ (fiş), корр. счёт, Дт, Кт, основание (`LINEEXP`/`GENEXP1`), контрагент/субконто, сальдо нарастающим итогом. Начинается со строки «Вх. сальдо». Инвариант: конечное нарастающее сальдо = исходящее ОСВ; при выборе родителя — движения по всем подсчетам (префикс).

**Анализ счёта.** По счёту и периоду: сальдо нач.; обороты по Дт в разрезе корр. счетов; обороты по Кт в разрезе корр. счетов; сальдо кон. Инвариант: Σ по корр. счетам = оборот счёта в ОСВ (по каждой стороне). Строится на парах корреспонденции (расчётные помечать).

**Журнал-ордер (ЖО) и ведомость.** [практика СНГ] ЖО ведётся по **кредиту** одного счёта (или группы): строки — записи, столбцы — корреспондирующие дебеты, итог — оборот Кт, внизу — итоги по дебетуемым счетам; ведомость к ЖО — аналитический учёт (Дт/Кт/сальдо по субконто). Классика: ЖО-1 касса (50), ЖО-2 расчётный/банки (51, 52, 55), ЖО-5 поставщики (60), ЖО-10 материалы, ЖО-11 затраты, ЖО-13 реализация… **Точная нумерация/состав у авторов расходятся — взять образцы у бухгалтера; ЖО-1..16 для Туркменистана не найдены.** Инвариант: итог по кредиту ЖО = оборот Кт счёта в ОСВ; Σ по графам Дт = итог Кт; сумма ЖО по всем кредитуемым счетам = Σ Дт оборотов. Мемориальный ордер [практика СНГ]: номер, дата, содержание, корр. счета, сумма, ссылки на документы, подписи.

**ОСВ по субконто.** Те же графы, строки — значения субконто (контрагент/договор/центр затрат) в рамках счёта. В Logo субконто = уровни 2–4 кода счёта (контрагент) и `CENTERREF` (центр затрат, только 7xx). Помнить: коды контрагентов между годами переиспользуются.

## 3. Формы по строкам (баланс, ОПУ)
- Бланков с кодами строк нет [НЕ НАЙДЕНО]. Рабочий макет [решение, предположение]: **конфигурируемая таблица строка → диапазоны счетов**; строки — минимальные статьи НСФО п.58 (баланс: ОС, нематериальные, запасы, торговая дебиторка, деньги, торговая кредиторка, налоговые обязательства, капитал и резервы…) и п.65 (ОПУ: выручка, расходы по финансированию, налог на прибыль, прибыль/убыток, ПСД). Графы баланса: «на начало года / на конец периода»; ОПУ: «текущий / предыдущий период».
- **Готовая основа в самой базе** [проверено]: `LG_<FFF>_FINTABLEITEM` (TABLEREF 1 — баланс Tekdüzen, 2 — себестоимость, 3 — отчёт о прибылях; `BEGCODE/ENDCODE` — диапазоны **только турецких** 3-значных кодов). Российских форм в ней нет. Использовать как стартовый макет формы по диапазонам.
- Инварианты баланса (Tekdüzen в Logo): классы 1,2 — активы; 3, 4 — обязательства; 5 — капитал; 6, 7 — результат/затраты. До закрытия года Σ нетто всех счетов = 0; после закрытия 6/7 ≈ 0, результат на 590/570 (закрывающие mahsup, текст «PEYDA-ZYYAN»). Актив = Пассив — проверять на конец периода; контрсчета (257/268 накопленная амортизация, 5xx убытки) идут со знаком «−».
- Строка формы = Σ нетто листьев в диапазонах; строка вне диапазонов и счета «не сопоставлено» выводить явно, итог по формам обязан сходиться с ОСВ.
- Российские обобщающие коды (SPECODE) — альтернативная группировка, надёжно не во всех годах .
